# Código do mrenamer

| Arquivo | Responsabilidade |
| --- | --- |
| `media_renamer.py` | Interface Tkinter/ttk, seleção, prévia e preferências |
| `rename_engine.py` | Validação, renomeação e recuperação de lotes |
| `requirements.txt` | Dependências do aplicativo |
| `requirements-build.txt` | Ambiente de empacotamento Windows |
| `media_renamer.spec` | Configuração canônica do PyInstaller |
| `MediaRenamer.spec` | Compatibilidade com o nome histórico do spec |

Consulte a [instalação](../../README.md), o [manual](../../docs/user-guide.md) e o [guia de desenvolvimento](../../docs/development.md).
